# Rob's fitness and looks improvement guide

Put the guide here (any of .md, .txt, .pdf, .docx, or images of pages). Then ask Claude to import it.

What "import" means: read the whole guide, then copy what the app needs into the app's own data so
nothing has to be typed in by hand. Nothing is invented: every item must come from the guide, and the
import is shown for review before it is saved.

Where each kind of content goes (these stores already exist):
- Exercises, rep ranges, programs/splits -> Exercise Library (`overload_exercises`) and `programs`
- Calorie/macro/protein rules, pace -> Coach goal templates and the coach engine rules
- Supplements and doses -> `supplements`
- Skincare routine, products, ingredient rules -> Look routine (`lm_profile.skinSteps`), tier routines
- Habits, daily standards -> `habits`, Mind standards
- Sleep, water, posture, grooming, style rules -> Recover / Water / Look / Style
- Anything else -> a Guide reference note in the app (searchable)
